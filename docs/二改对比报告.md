# 二改对比报告 · naraka-souljade v2.0-ext

> 数据全部由扩展层实时调用主引擎 `totals()` / `damage()` 算出，
> 与页面「属性 / 期望」面板同源同口径。
> 复现命令：`node tools/nsj-harness.js`（61 用例）+ 下表的采集脚本见文末。

## 一、上游 6 套推荐配装的实测基线

「满词条」= 用扩展的 `polishCurrent()` 把这 6 套的 4×7 格词条坐标下降到最优
（魂玉集合不动，只换词条填法）。这一步本身就是一次「不换玉的纯词条收益」检验。

| 推荐配装 | 元素 | 武器 | 上游默认词条 DPS | 满词条后 DPS | 词条可挖掘空间 | 相对基准 |
|---|---|---:|---:|---:|---:|---:|
| 百化冰陨流 | ❄ 冰 | 近战 | 34,162 | **46,333** | **+35.6%** | 1412 → 1915 |
| 百化冰斩 | ❄ 冰 | 近战 | 23,126 | 32,305 | +39.7% | 956 → 1335 |
| 奔雷陨 | ⚡ 雷 | 近战 | 23,577 | 34,738 | +47.3% | 975 → 1436 |
| 魂反弓 | ☠ 毒 | 弓箭 | 20,934 | 31,491 | +50.4% | 866 → 1302 |
| 毒炮陨 | ☠ 毒 | 火炮 | 21,554 | 30,428 | +41.2% | 891 → 1258 |
| 三才套 | ☠ 毒 | 近战 | 13,368 | 18,944 | +41.7% | 553 → 783 |

**结论 1**：上游 6 套推荐配装的词条填法普遍没铺满收益 —— 光是同玉换词条就有 35%~50% 的涨幅，
不需要换任何一颗魂玉。

## 二、求解器找到的全局最优

扫描口径：3 元素 × 4 武器 × 7 槽位，深度模式，199 万次评估 / 92 秒。

### 2.1 最优配置

| 项 | 值 |
|---|---|
| 综合期望 DPS | **105,815 /秒** |
| 相对基准 | **4,374.8**（空装配装 = 100） |
| 元素 / 武器 | 冰 / 近战通用 |
| 相对上游最强推荐（百化冰陨流默认） | **+209.7%** |
| 相对上游最强推荐（满词条） | **+128.4%** |

魂玉与词条：

| 槽位 | 魂玉 | 4 格词条 |
|---|---|---|
| 1 | 元素奔涌 | 暴击伤害 +25% / 冰爆伤害 +30% / 对首领 +5% / **合道** |
| 2 | 爆冰诀 | 冰爆伤害 +30% / **枚卜 ×3** |
| 3 | 连续冰爆 | 暴击伤害 +25% / 冰爆伤害 +30% / 对首领 +5% / **合道** |
| 4 | 游雷振 | 暴击伤害 +25% / 冰爆伤害 +30% / 对首领 +5% / **合道** |
| 5 | 淬毒术 | 暴击率 +3% / 暴击伤害 +25% / 冰爆伤害 +30% / **合道** |
| 6 | 焚燃 | 暴击率 +3% / 暴击伤害 +25% / 冰爆伤害 +30% / **合道** |
| 7 | 烈元诀 | 暴击伤害 +25% / 冰爆伤害 +30% / 对首领 +5% / **合道** |

**结论 2**：最优解＝**冰爆体系 + 6 条合道 + 3 条枚卜**。
- 6 条合道把冰爆伤害词条从 +30% 放大到 +60%（×2），雪球效应最强；
- 枚卜堆在爆冰诀上（该玉本身 +35% 冰爆伤害 / −33% 冷却），双暴判定把暴击期望再抬一档；
- 游雷振、淬毒术这两个「不看元素」的玉被选进来，纯粹为了它们能塞满 6 个合道位＋元素积累 +60%；
- 冰渊爆（+60% 冰爆）反而落选 —— 它没有可叠加的机制，被「合道×6」的整体倍数盖过。

所以近战/火炮/弓箭/斩马刀算出来一个数。

## 三、求解器正确性

`node tools/nsj-validate.js`：单练池前 14 颗的 C(14,7)=3432 套全组合暴力枚举，
每套做完整词条坐标下降，与求解器结果对撞。

| 口径 | 求解器 | 暴力枚举 | 差 |
|---|---:|---:|---:|
| ❄ 冰 / 近战 | 105,815 | 85,720 | **−23.4%（求解器更优）** |
| ⚡ 雷 / 近战 | 67,341 | 67,341 | 0.00% |
| ☠ 毒 / 火炮 | 67,341 | 67,341 | 0.00% |
| ☠ 毒 / 弓箭 | 67,341 | 67,341 | 0.00% |

冰套那 −23.4% 是**求解器赢**：暴力池按「单练分」排序，爆冰诀 / 连续冰爆这类
单练不出彩但成体系才爆发的玉被排到池外；求解器的贪心 + 池枚举不走单练排序。

## 四、动态对比 vs 持久化，边界实测

| 操作 | localStorage key 变化 | 历史条数变化 |
|---|---|---|
| 冻结当前为动态 A | 0 | 0 |
| 冻结当前为动态 B | 0 | 0 |
| 互换 A/B | 0 | 0 |
| 改一颗玉的词条 | 0（仅写上游 `naraka-souljade-v1`） | +1 |
| 载入推荐配装 | 同上 | +1 |
| 求解出新高 | +0（写到既有 `ext-best` key） | +1（求解结果也记一条） |
| 浏览器刷新 | — | 保留 |

**结论 3**：「动态对比不落盘」是硬边界 —— 冻结/互换 A/B 全程只写内存对象，
刷新即消失；只有「历史快照」和「最高记录」两个明确产物会持久化。

## 五、怎么自己复现这张表

```bash
# 1) 上游 6 套基线 + 词条挖潜
node -e '
const {boot}=require("./tools/nsj-dom-stub");
const {N,EXT}=boot();
for(const p of N.PRESETS){
  N.applyPreset(p.id);
  const a=EXT.metricsOf(EXT.currentConfig()).dps;
  const b=EXT.metricsOf(EXT.polishCurrent(EXT.currentConfig())).dps;
  console.log(p.name, a.toFixed(0), "→", b.toFixed(0), (100*(b/a-1)).toFixed(1)+"%");
}'

# 2) 全局最优（深度，约 90 秒）
node -e '
const {boot}=require("./tools/nsj-dom-stub");
const {N,EXT}=boot();
N.applyPreset("bingyun");
EXT.solve(EXT.currentConfig(),{swapRounds:2,seedKeep:6,restarts:3,poolSize:14,refineN:16,
  elements:["ice","thunder","poison"],weapons:["melee","cannon","bow","zhanmadao"],
  topReport:6,budgetMs:600000,expandSlots:false}).then(r=>{
  console.log("最优",Math.round(r.best.metrics.dps),"基准",r.best.metrics.index);
  r.best.slots.filter(Boolean).forEach((s,i)=>console.log(i+1,EXT.jadeName(s.jadeId),s.subs.join(" / ")));
});'

# 3) 暴力交叉验证（约 3 分钟）
node tools/nsj-validate.js --top 14 --pick 7
```
